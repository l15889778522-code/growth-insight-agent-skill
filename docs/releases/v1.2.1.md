# v1.2.1

v1.2.1 是运行合同 v1.2 的发布收尾版本，不改变仓库根目录的 `VERSION=1.2`，现有 v1.2 运行产物无需迁移。

## 主要内容

- 提供 Codex 原生七角色数据分析工作流：Business、Metrics、SQL、Insight、Visualization、Review 和 Report。
- 每个阶段在用户确认后才向下游传递；SQL 产物批准与真实查询批准相互独立。
- Metrics 阶段支持稳定 ID、版本化的指标新增、修改和删除。
- 支持运行状态、审批日志、哈希链、checkpoint、执行租约、精确回退和 v1.1 迁移审计。
- SQLite 与 MySQL 使用统一只读数据库适配器；查询审批绑定 SQL、数据源身份、TLS 和执行限制。
- 支持不可变查询结果、数据画像、PNG/HTML 图表、血缘清单、Markdown 报告和运行摘要。
- 安装器支持个人级和项目级安装、验证、升级、卸载与事务回滚。

## 发布验证

- 本地离线测试：`137 passed, 2 skipped`；跳过项为需要显式启用的真实 MySQL 测试。
- Windows 安装器专项：`10 passed`。
- GitHub Actions：Windows/Ubuntu、Python 3.11/3.12/3.13、Windows/Ubuntu 干净安装和 MySQL 8.4 发布门共九项通过。
- MySQL 8.4.11：TLS 只读账号、写入拒绝、流式读取、行数和字节限制、Decimal、Unicode、超时、中途断连和新连接重试通过。
- Codex 原生 Agent：Business -> Metrics -> Review 真实 smoke 与 Git 对象重放审计通过。

## 已知验证缺口

- 第二台同账号 Codex 的安装、重启和可见 Agent smoke 尚未执行。用户已接受该风险并批准本次发布，不能据此宣称跨设备验收完成。
- 完整七角色真实 Agent 链尚未作为一次发布级 smoke 全程运行；当前真实证据链止于 Review。
- 三模式真实评测尚未执行，因此本版本不宣称受控 Skill 优于单 Codex 或 Codex 原生自由编排。
- 分支覆盖率约为 75%；关键发布路径已经自动化，但仍有继续扩充边界覆盖的空间。

## 后续评测纪律

三模式评测分为单 Codex、Codex 原生自由编排和当前受控 Skill。发布后每次只在用户明确指令下启动一个模式，保存该模式的独立原始结果后停止；不得自动继续其他模式，也不得在三种模式未完成统一比较前形成优劣结论。
