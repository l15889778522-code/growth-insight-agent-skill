# v1.2.3

`v1.2.3` is a personal-workflow patch release for the Codex-native data analysis Skill.

## Release metadata

- GitHub repository: `l15889778522-code/growth-insight-agent-skill`
- Release tag: `v1.2.3`
- Runtime contract version: `1.2`
- Release source: the `agent/native-free-eval` branch after the release commit

## Included changes

- Keeps all seven permanent Agent roles while allowing personal runs to choose only the roles needed for the question.
- Keeps the main route stage-serial and adds an explicit stage-local policy for at most two independent analysis branches.
- Adds deterministic checks for branch count, branch purpose, current-stage state, supported roles, and shared approved input hashes. Seven-way Agent fan-out is not allowed.
- Keeps SQL execution, result publication, and final Report publication outside stage-local parallelism and behind their existing approval gates.
- Keeps `growth-sql` on `gpt-5.6-luna` with `max` reasoning effort.
- Retains readable Chinese stage reports, compact personal-mode state output, Metrics workbench editing, Review-terminal completion, and the existing read-only evidence chain.

## Verification

- Skill structure validation passed.
- Full offline regression: `182 passed, 2 skipped` on Windows Python 3.12.
- The skipped tests are explicit live MySQL checks; no real Agent evaluation was run for this release.
- Temporary test directories were removed and `git diff --check` passed.

## Known limits

- Stage-local parallelism is currently a bounded scheduling and input-freezing capability. Independent branch response registration, automatic structured merging, and conflict presentation remain `PARTIAL` work for a later release.
- `VERSION=1.2` remains the runtime contract version. Existing v1.2 run records do not need migration solely because this patch was released.
- Cross-device acceptance, real three-mode Agent evaluation, and broader database coverage remain deferred.
